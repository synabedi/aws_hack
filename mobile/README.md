# JalMaapi mobile (`mobile/`)

React Native (Expo) Android app for the officer on the move. Same API contract as the dashboards
(`web/API.md`, `contracts/schemas.py`), same decision maths (`src/model.js` is shared with `web/desk`).

Screens: Sites (ranked by time left to decide), Site desk (depth, Intervention Clock, forecast chart,
vehicle verdicts, FloodLab, drain health), Approvals (officer ID, Approve / Reject, Hindi and English
advisory), Pumps (forecast plan against the baseline).

## Run on a phone (fastest)

    cd mobile
    npm install
    npx expo start

Install **Expo Go** from the Play Store, then scan the QR code. Phone and laptop must be on the same Wi-Fi;
if the QR code does not connect, use `npx expo start --tunnel`.

## Build an installable APK

    npm install -g eas-cli
    eas login                      # free Expo account
    eas build -p android --profile preview

The build runs in Expo's cloud and ends with a link to download the `.apk`.

## Data

With no API address the app uses the demo snapshot in `assets/mock` (generated by
`web/desk/make_demo_data.py` from the physics model) and shows a "Demo snapshot" label.
To use the real API, type its address on the Sites screen, or set `EXPO_PUBLIC_API_BASE` before starting.
